# 附属 raw 扩展与减字谱排版设计

本文记录 2026-10-08 的接口讨论、排版需求及第一版实施结果。通用 `tracks` 接口与减字谱 `init-track()` 适配器已实现；尚未约定的跨音符功能不在本版范围内。

## 目标与依赖关系

`jianpu` 应允许外部包扩展附属 raw 类型，同时完全不依赖、也不内置对 `jianzi` 包的识别。普通用户只使用现有简谱功能，不必安装减字谱包。

使用者初始化扩展包提供的处理器，再显式传给 `jianpu`。仅仅导入扩展包不会自动修改已经导入的简谱函数。可以用 `.with(...)` 包装一次，避免每次调用重复注册。

当前调用形式如下；本地跨仓库编译时，根目录需包含两个仓库：

````typst
#import "jianpu.typ": jianpu
#import "../typst-jianzi/jianzi.typ": init-track

#let jianzi-track = init-track(style: "kai")

#let qin-score = jianpu.with(
  tracks: (jianzi: jianzi-track),
)

#qin-score(
  ```melody
  1 2 3 4 |
  ```,
  ```jianzi
  大九挑七 名十一中食抹一 _ 大九 |
  ```,
)
````

相邻仓库 `typst-jianzi` 的 `init-track()` 内部复用 `init()` 返回的单字符串渲染函数，提供 `parse`、`render-item` 和默认 `height: 2em`。适配器实现位于 `track.typ`，不导入简谱包。

## 已约定的减字谱输入语法

raw 顶层用空白分隔不同排版项，普通减字直接书写。结构内的成员统一由英文逗号（ASCII `,`）分隔，解析器必须先识别方括号结构，不能直接按所有空格拆分源码。

| 写法 | 含义 |
| --- | --- |
| `大九挑七` | 一个普通减字 |
| `_` | 跳过一个主音符位置 |
| `a[减字一]` | 单字注释，成员盒高为整体盒高的一半，底边对齐 |
| `a[减字一,减字二]` | 注释组，成员从上到下竖排，最多四个 |
| `g1[减字组一,减字组二]` | 横向减字组，索引从 `0` 开始，第二个成员作为对齐基准 |
| `g[减字一,减字二]` | `g0[减字一,减字二]` 的简写，以第一个成员作为对齐基准 |
| `g0[减字一,a[减字二,减字三]]` | 横向组中嵌套竖向注释组，第一成员作为基准 |

`a` 可以嵌套在 `g` 中；作为一个完整的横向成员，其参考中心按整个竖向组的盒宽计算。`a` 内部的多个字不独立消耗旋律位置。

顶层的一个普通减字、一个 `a[...]` 或一个 `gN[...]` 都只对应一个主音符位置。`gN` 的数字 `N` 是成员索引，不是数量，也不是旋律音符编号。例如 `g1[甲,乙]` 对齐 `乙`，`g0[甲,乙]` 对齐 `甲`。

参考索引为 `0` 时允许省略数字：`g[...]` 与 `g0[...]` 完全等价，解析后都记录为索引 `0`。选择其他成员仍须显式写出数字。

横向组各成员采用自己的内部比例：普通减字占完整盒高，单字注释占下半部，多字注释组使用完整高度。整体按盒子底边组合，再返回一个统一基准高度的外层布局盒。

`a` 与 `g` 的成员分隔符统一为英文逗号 `,`。暂不支持中文逗号 `，` 作为分隔符，也不自动将它转换为英文逗号；组中误用中文逗号应明确提示使用英文逗号。

组内允许成员之间留空白，空白不应把整个组拆成多个音符项。暂不约定 `a` 中嵌套 `g`、`a` 嵌套 `a` 或 `g` 嵌套 `g`。成员不能为空；`a` 超过四成员、`gN` 索引越界及括号不匹配应明确报错。`_` 目前只约定为顶层占位，没有约定组内占位。

## 已约定的解析与对齐模型

扩展描述先只要求两个函数：

```typst
(
  parse: function,
  render-item: function,
)
```

- `parse(source)` 接收整个 raw 字符串。复杂关键字、分组、状态切换由扩展解析，简谱包不能预先按空格破坏结构。
- 解析结果是一个按音符顺序排列的数组。每一项消耗一个主音符位置。
- `none` 表示跳过一个位置；非空项作为不透明数据传给 `render-item`。
- 不透明数据可以是字符串、字典等，简谱包不解读扩展内部的语法。
- 当前不增加 `ranges` 或范围绘制接口，也不增加 `span`。此前 `span` 的用途是在多个音符范围内居中，暂时没有此需求。

基本解析结果示例：

```typst
(
  "大九挑七",
  "名十一中食抹一",
  none,
  "大九",
)
```

对于减字谱的基本语法，空白分隔独立排版项，`_` 解析为 `none`。独立小节线 `|` 可以作为源码阅读辅助，不消耗位置。其他特殊字符由减字谱扩展决定含义，不采用英文歌词的连字符拆词规则。

附属 track 对齐前面最近的一条旋律，并跟随它分行；多个附属 track 按输入顺序上下排列。每项对应当前歌词模型中的一个主音符位置：和弦整体占一个位置，倚音与延音横线不消耗位置。项数不得超过旋律可用位置，较短的数组不必补满。

简谱包负责测量渲染结果，计算最小横向间距、垂直占位和分行。关键词本身可以不消耗位置，仅修改后续项的数据或样式。

## 当前歌词字号的实际状态

当前歌词默认继承调用位置的正文字体家族，但不继承正文字号。字号是简谱 `size` 的 `0.92` 倍；默认简谱 `12pt` 时，歌词为 `11.04pt`。

这只是现有实现的记录。本次讨论没有要求改变歌词字号，也不应把此系数自动用于外部扩展。减字谱的大小遵循下面的独立需求。

## 减字谱大小与竖向注释组

设简谱字号为 `S`。

### 普通减字

普通减字的布局盒在简谱中统一缩放到 `2S` 高。例如简谱 `size: 12pt` 时，最终盒高为 `24pt`。SVG 减字与 fallback 字符使用相同的 `24pt` 字号及完整 `1em` 字位，不按单字笔画边界分别放大。

实际占位以扩展返回的内容测量为准；简谱包不能只凭字号假定其宽高。

### 注释类型减字

存在另一种注释类型的减字。单字注释由 `jianzi` 内部控制为整体布局盒的一半高，放在盒子的下半部。整体盒仍缩放到 `2S`，其中单字注释的成员盒高及字号最终为 `S`，SVG 与 fallback 使用相同缩放比例。

使用 `a[减字一,减字二]` 串起最多四个注释减字，按输入顺序从上到下叠成一列。单字注释写作 `a[减字一]`。

多字注释组具有以下要求：

- 整组高度与普通减字的大小一致，目标为 `2S`。
- 单字按比例缩放，组宽由缩放后的单字宽度及实际横向边界决定，不能保留普通减字的宽度。
- 整组作为一个减字单元处理，占一个音符位置；解析数组中不能把各成员展开为多个音符项。
- 纵向排列、缩放和组内间距由减字谱扩展处理，简谱包使用最终内容的尺寸排版。
- 超过四个成员应由扩展解析器明确报错。

普通减字、单字注释、多字竖排组及横向混合组均返回相同基准高度的外层布局盒。单字注释仅填充下半部，多字竖排组使用完整高度；其相对比例全部由 `jianzi` 管理。双字组在无额外间距时可以各占盒高一半；三字、四字组需要缩小。组内间距及缩放的精确公式后续确认，不能因添加间距使总高度超过目标。

### 底边对齐与带基线的盒子

单字注释减字与普通减字沿下方对齐。这里的“下方”明确指 `jianzi` 渲染函数返回的 box 的下边缘，不是文字基线，也不是内部 SVG 中可见笔画的最低点。

当前 `jianzi` 包在可生成减字时返回一个带 `baseline` 的 box，内部包含 SVG；fallback 分支则返回真实文字，见下一节。基线用于它参与正文内联排版时的定位，不能直接用作这里的底边对齐依据。

缩放必须作用于整个减字盒子，并使测量得到的占位尺寸反映缩放后的宽高；只缩放内部 SVG，或只改变视觉大小而保留原盒宽高，都会使对齐和避让失真。`jianzi` 在内部基准尺寸下完成组合，`jianpu` 再统一缩放内容、占位尺寸及横向锚点。

若最终外层盒高为 `2S`，共享底边为 `B`，普通减字成员盒顶为 `B - 2S`，单字注释成员盒顶为 `B - S`。单字注释的外层盒顶仍为 `B - 2S`，上半部留白；外层盒宽依据缩小后的成员宽度确定，不因补齐高度而补成正方形。实际放置应依据最终盒子的边界，不能因内容带有基线而产生额外的上下偏移。

### SVG 与 fallback 字符混合

依据相邻仓库 `typst-jianzi/docs/architecture.md` 的状态处理及内联排版约定，当前单字渲染有四种结果：

- `Renderable`：返回包含 SVG 的内联 box，采用固定 `1em` 方形字位及字库提供的基线度量，不根据笔画轮廓收紧占位。
- `Fallback`：返回配置 fallback 字体的真实 Typst `text`，不创建 SVG 或方形 box；字号、基线、颜色等继承调用环境，宽高由原生文字排版决定。
- `Empty`：返回 `none`。
- `Missing`：组合中缺失组件时报错，不能作为 fallback 字符或空白处理。

因此同一个竖向注释组、横向组都可能同时包含 SVG 盒子和普通字符。扩展组合器必须接受任意 content，不能假定所有成员都是图片，也不能依赖检查成员是否为 `box` 来决定布局。

由减字谱 track 适配器在内部基准尺寸及统一测量环境中渲染每个成员，再将结果整理为可明确定位、具有统一基准高度的外层布局盒。这里的外层盒是组合排版用途，不改变基础 `jianzi()` 在正文中返回真实 fallback 文字的设计。

测量及组合需遵循以下要求：

- 对 SVG 成员保留返回 box 的字位边界，不读取或裁切 SVG 可见笔画。
- 对 fallback 成员使用真实文字的排版宽高，明确用于测量的文字上下边界；不能假定其高度、宽度或 descent 与 SVG 字位相同。
- 各成员的测量、缩放和最终放置使用一致的环境，不能先按普通文本测量，再按不同字号、基线或文字边界放置。
- 竖向组的目标高度 `2S` 包含所有成员的最终占位高度和组内间距。混合成员不能简单用“成员数 × 字号”估算高度，应按实际组合尺寸求缩放并复核最终占位；不得只缩放图片、遗漏 fallback 字符。
- 底边对齐使用成员或组合的最终外层盒下边缘，避免内联基线引入额外偏移。fallback 的可见笔画底部不作为另一套对齐基准。
- 横向组的宽度、参考成员中心和左右占位都由实际布局得到；fallback 字符不一定是全角，不能用成员序号乘固定 `1em` 来推算锚点。
- fallback 保留初始化时配置的字体和调用环境的文字样式，不应为了混排重新按简谱数字字体绘制。

若实际绘制过程中得到 `none`，组合器需要明确选择忽略空成员还是报告无效组，不能将它当作具有尺寸的字符。raw 中明确的 `_` 仍然是在 track 层消耗一个音符位置的占位，与组内空渲染结果不同。

测试覆盖 SVG/fallback 混合组合、单字半宽、固定盒高和不同参考成员的锚点。真实跨仓库样张位于 `jianpu/tests/jianzi.typ`；减字谱侧解析与几何断言位于 `typst-jianzi/tests/track.typ`，无效语法纳入原有错误测试。

## 同一音符下的横向多减字与指定锚点

一个音符下方可以横向排放多个减字，并明确指定其中一个作为与简谱数字居中对齐的参考。

这与跨多个音符居中的 `span` 不同：整组仍然只消耗一个音符位置。竖向注释组也可作为横向组中的一个减字单元。

扩展解析器应将 `gN[...]` 横向组保留为一个数据项，包括各成员以及从 `0` 起算的参考索引 `N`；成员可以是普通减字或 `a[...]` 注释组。渲染器负责组合成员，并把参考成员在整个内容中的横向中心传给简谱布局器。

因此，仅返回普通 content、始终按盒子中心对齐，已经不足以覆盖此需求。`render-item(data)` 统一返回字典：

```typst
(
  body: content,
  anchor-x: length,
)
```

`body` 是内部排版完成的整体 box；`anchor-x` 是相对该盒左缘、缩放前的横向对齐点。普通单字和独立注释组返回盒宽的一半，横向组返回指定成员的中心。所有非空项使用同一协议，不再同时支持直接返回普通 content。

`parse(source)` 只返回语义数据，不生成布局盒；`render-item(data)` 负责成员渲染、SVG/fallback 混排、内部缩放及组合。`jianpu` 只消费最终盒子和锚点。

设内容测量宽度为 `W`，锚点为 `A`，对应音符数字的中心为 `X`，则：

- 内容左缘：`X - A`。
- 锚点左侧占位：`A`。
- 锚点右侧占位：`W - A`。

宽度避让应使用这两个不对称占位，不能继续假定左右各占 `W / 2`。例如横向组的第一个减字被指定为参考时，大部分组宽会向音符右侧延伸。

最小间距需要计入完整内容，包括参考减字左右的其他成员；不能只测量被指定的那个减字。分行仍跟随旋律小节边界。

### 横向外伸与相邻内容避让

允许歌词单词或减字组超过简谱行的左、右边缘。简谱行边缘不是附属内容的硬裁切边界，不要求为使附属内容落在简谱行宽内而移动对齐锚点、缩小内容或额外扩大行首、行尾空间。

附属内容也可以延伸到相邻音符下方，包括 `_` 跳过的空位置。避让边界由同一附属行内相邻的可见内容决定，而不是每个音符自身的盒宽。

对于横向锚点不对称的两项，所需锚点距离至少为“前项锚点右侧宽度 + 最小间隙 + 后项锚点左侧宽度”。不足的距离进入旋律的间距与分行计算；空项不建立可见内容边界。

本次确认允许超过简谱边缘；没有另外约定超出页面边缘时的处理方式，不应将两种边缘混为一谈。

## 整体缩放协议与后续待定项

不需要向 `jianzi` 的渲染函数传入简谱字号。`render-item(data)` 返回内部组合好的布局盒及横向锚点；普通减字与注释的比例由盒内布局表达，不回传逐项的 `height-factor`。

整个扩展 track 的目标高度字段是 `height`，默认 `1em`；`init-track()` 提供 `2em`。这是通用 track 尺寸配置，不是识别 `jianzi` 名称的特殊规则。其他扩展不必采用减字谱的 `2S`。可选 `gap` 指定相邻项最小间隙，默认 `0.2em`，两个字段的 `em` 均明确按简谱 `size` 解析。

设原布局盒宽高为 `W`、`H`，横向锚点为 `A`，则简谱侧对减字谱 track 使用缩放比例 `k = 2S / H`。最终占位为 `kW` 与 `2S`，最终锚点为 `kA`，左右占位分别为 `kA` 与 `k(W - A)`。盒高必须大于零。

单字注释上半部的留白属于约定的完整布局盒，缩放前不能裁掉，否则会把半高注释错误放大成普通减字。整盒 SVG 与 fallback 文字共同缩放；上下对齐使用缩放后的外层盒边界。

## 第一版实施细节

- 注册参数采用 `tracks`；处理器描述必须提供函数 `parse` 和 `render-item`。内置 raw 类型不可覆盖，未注册类型明确报错。
- `render-item` 在 Typst context 中调用。非空项必须返回正宽高的 content 和盒内锚点；简谱侧先测量，再使用带 `reflow: true` 的整体缩放，同时更新锚点及占位。
- 减字谱内部盒高统一为 `20pt`，与调用环境字号无关；缩放后的显示大小由简谱侧决定。普通成员（含 fallback）使用相同字号和完整 em 字位，注释和横向组随后在同一尺寸体系中组合。
- 单字注释占下半部。多字注释组的间隙为内部盒高的 `0.04` 倍，间隙计入总高度；横向组内间隙为盒高的 `0.08` 倍。
- fallback 字符使用字库的 ascent/descent 确定字位上下边缘，保留原生字宽，不依字符笔画高度重新缩放。SVG 保留原方形盒边界。组内空结果报错。
- 简谱侧与歌词共用位置计数、宽度避让和逐行切分，扩展项在自己的附属行中按盒底放置。显式 `_` 保留该行的目标高度。
- 未实现 `ranges`、`span`、多声部时长对齐及跨页附属内容拆分。已有的边缘外伸约定仍适用。

目前没有约定跨音符范围装饰、跨音符居中或复杂扩展占用旋律时长；不要在第一版中自动引入这些功能。
